## О проекте

**Sonic Mod Commissions** — веб-сайт, посвящённый заказу игровых модификаций для проектов серии Sonic.

Сайт позволяет ознакомиться с примерами выполненных работ, сформировать заказ на модификацию и получить предварительную оценку её стоимости.

## Возможности

- Формирование заказа на игровую модификацию.
- Предварительный расчёт стоимости.
- Просмотр примеров выполненных работ.
- Поддержка нескольких языков интерфейса.
- Адаптированный интерфейс с тематическим оформлением Sonic.
